# Phoenix screened OASST2: private human review (experimental; NO training approval)

The 17 September 2026 three-way real-source comparison [#35190120239](https://github.com/Cola968/neral-helios/actions/runs/35190120239) measured 1,200 selected candidate examples from 1,200 different conversation trees: 400 DE and 800 EN; no rows were lost to the exact-prompt deduplicator. The preliminary pattern screen found zero email, phone, short/long answer and >512-character prompt flags among the selected rows, **but one duplicate normalized answer remained**. These results do not establish answer correctness, privacy, source attribution, licensing or semantic holdout independence. The existing source export path and model weights are unchanged.

## Why a separate review queue?

Human review cannot be replaced by regex. The separate `phoenix_private_review_queue.py` tool makes a deterministic, balanced **24-row** sample: six DE train, six EN train, six DE validation and six EN validation. Source texts are written only to a new JSONL file inside the existing private NERAL assets directory. An adjacent JSON receipt contains only counts, the source pin and a candidate identity digest; the script prints neither text, IDs nor private paths. The script refuses a Git working tree as the asset root, symlinks/out-of-root outputs, overwrites and missing/corrupt upstream archives. Use `--execute` explicitly. No scheduled execution, GPU allocation or training.

Review fields on each row initially say `pending`: `privacy_review`, `attribution_review`, `answer_quality_review` and `semantic_holdout_overlap_review`. Open the **private** JSONL locally; never attach it to GitHub issues, public chat or Actions logs. Check question-answer correctness, harmful/incorrect guidance, source licenses/attribution and sensitive personal information. Review duplicated generic answers and representativeness manually. Mark a reviewed copy privately and retain the original SHA-pinned receipt. Do not treat reviewing only these 24 rows as certifying the other 1,176 examples; increase or stratify review when needed.

A real new and independently reviewed holdout v2 (24–100 private questions and rubrics), semantic overlap assessment, legal/source review and independent SHA-bound approval are still required **before** any experimental 1–50-step SFT. Neither this queue nor the filtered candidate is a training pack. Never turn `training_approved` on solely because the pattern-screen numbers are zero. No inference throughput, training throughput or model-quality improvement has been measured by this work.
