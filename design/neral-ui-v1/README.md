# NERAL UI – Version 1 (Designstand)

Erster festgehaltener, vom Nutzer zur Speicherung ausgewählter Oberflächenentwurf vom 6. November 2026 (zuvor „Entwurf 04“).

## Öffnen

`index.html` lokal im Browser öffnen. Die gesamte Vorschau liegt in einer einzelnen Datei mit HTML, CSS, Inline-SVG und JavaScript; externe Pakete oder Webdienste werden nicht benötigt.

## Gestaltung

- Chat zuerst: ruhige, dunkle Oberfläche ohne Begrüßungskarten oder dekorative Effekte.
- Schmale Seitenleiste mit Chatverlauf, Projekten und Agenten.
- Kompakte Nachrichteneingabe; Denkmodi und Werkzeuge werden erst bei Bedarf geöffnet.
- Responsive Vorschau für Desktop und schmalere Ansichten.

## Abgrenzung

Dies ist ein **interaktiver Designprototyp** mit Beispieldaten und simulierten Oberflächenzuständen, **keine produktive NERAL-App**. Es gibt keine Verbindung zur lokalen Modellinferenz und keine echten Datei- oder Agentenaktionen. Die bestehende Oberfläche unter `templates/` und `static/` wird bewusst nicht verändert.

Diese Version ist ein eingefrorener Ausgangspunkt für künftige UI-Iterationen; Änderungen daran sollen nachvollziehbar bleiben.
