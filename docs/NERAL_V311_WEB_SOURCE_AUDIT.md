Eine Antwort mit explizit korrektem Plattformhinweis und belegter Ausnahme wird akzeptiert. Für einen vollständigen Live-Web-E2E-Vergleich sind tatsächliche Webseitenabrufe und Quellengültigkeit separat nötig; ein Modell, das vorab geprüfte Quellenauszüge erhält, wird ausdrücklich als **quellengestützter Modellvergleich**, nicht als Websuche-End-to-End bezeichnet.
