NERAL 1.0 LOCAL – START HIER (WINDOWS)

1. ZIP-Datei herunterladen und komplett entpacken (Rechtsklick -> Alle extrahieren).
   NERAL nicht direkt aus dem ZIP-Archiv starten.

2. Im entpackten Ordner NERAL-1.0-Local auf
   Start NERAL 1.0 Local.cmd doppelklicken.
   Beim ersten Start fragt NERAL, ob die benoetigten Python-Webserverpakete
   in einer eigenen Umgebung installiert werden duerfen. Bei Zustimmung J eingeben.

OPTIONAL: STAERKERER MODUS (EXP. QWEN3.5)
Wenn qwen3.5:9b bereits mit ollama list installiert ist, kannst du
stattdessen "Start NERAL 1.0 Stark.cmd" doppelklicken.
Dies nutzt qwen3.5:9b im gemessenen 2048-Token-Profil, unveraendertes
lokales Modell, kein Download. Die neue Vergleichsmessung ergab 31/36
richtige Antworten mit Qwen3.5 gegenueber 13/36 mit Qwen3:8B
auf 36 randomisierten ENTWICKLUNGSAUFGABEN (kein echter Blindtest).
Vier Qwen3.5-Antworten wurden nicht vollstaendig abgeschlossen.
Der normale Start bleibt jederzeit verfuegbar. Nur EINEN Starter
gleichzeitig ausfuehren; vor einem Wechsel die alte App beenden.

3. NERAL oeffnet sich automatisch im Browser.
   Dort kannst du bei Bedarf unter Anmelden ein lokales Konto erstellen.

WICHTIG:
- Ollama muss bereits installiert und gestartet sein.
- Das Modell qwen3:8b muss schon in Ollama vorhanden sein.
- Es gibt keine automatischen Modelldownloads.
- Die App ist lokal und hat keine Abo- oder Bezahlpflicht.
- Falls der Start fehlschlaegt, das geoeffnete Fenster lesen.
- NERAL startet auf http://127.0.0.1:9690/ und ist nicht oeffentlich erreichbar.
- Das Modell ist ein lokales Qwen-Basismodell; kein freigegebener NERAL-LoRA-Release.

Bei spaeteren Starts nur Schritt 2 wiederholen. Die lokalen Konten und Chats
bleiben im Windows-Benutzerverzeichnis gespeichert.

Dies ist ein gepruefter Release-Kandidat, keine stabile oeffentliche 1.0.
